# Zps Portfolio Web

This project is the front-end of my personal portfolio project: <https://www.zachschroeder.dev/>
It was originally generated with angular version 16.0.2.

It is deployed to Vercel via a GitHub integration.
The configuration in Vercel is mostly default, except for the build command, which can be found in Settings > Build and Deployment.

This is the build command:

`npm run env-variables && ng build`
